About Baby Cry Classification

Project Overview

This Baby Cry Classification system uses advanced deep learning techniques to automatically identify the reason behind a baby's cry. The system can classify cries into 5 categories:

  • Belly Pain: Discomfort due to gas, colic, or digestive issues
  • Cold/Hot: Temperature discomfort
  • Discomfort: General discomfort or irritation
  • Hungry: Need for feeding
  • Tired: Need for sleep or rest

Model Architecture

Our hybrid model combines multiple state-of-the-art techniques:

1. Wav2Vec2 Feature Extraction

Pre-trained Wav2Vec2 model extracts high-level audio representations from raw audio waveforms.

2. Bidirectional LSTM

BiLSTM processes sequential audio features to capture temporal dependencies in both forward and backward directions.

3. Attention Mechanism

Attention layer focuses on the most relevant parts of the audio sequence for classification.

4. CNN for Spectrograms

Convolutional Neural Network processes mel-spectrograms to extract spatial-frequency features.

5. Traditional Audio Features
  • MFCC: Mel-frequency cepstral coefficients
  • Spectral Features: Spectral centroid, rolloff, bandwidth
  • Rhythm Features: Tempo and onset strength

Data Processing

Dataset

The model is trained on baby cry audio data from Kaggle, containing recordings across 5 cry types.

Data Balancing

We use SMOTE (Synthetic Minority Oversampling Technique) to address class imbalance in the dataset.

Data Augmentation

Audio augmentation techniques include:

  • Gaussian noise addition
  • Time stretching
  • Pitch shifting
  • Time shifting

Performance

The model achieves high accuracy through ensemble learning and multi-modal feature fusion. Performance metrics include precision, recall, and F1-score for each cry type.
