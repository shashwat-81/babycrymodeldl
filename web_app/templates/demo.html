Demo flow

1. Record
Capture a 1–10 second cry clip near the baby. Minimize background noise.
2. Upload
Submit through the dashboard or send via cURL to /upload.
3. Interpret
Review the predicted class, confidence, and caregiver guidance.

Recording tips

  • Avoid overlapping adult speech, music, or TV audio.
  • Keep device 20–40 cm from the baby for clarity.
  • Ensure recording is neither too quiet nor clipped.
  • Provide dedicated clips per cry instance.

Non-baby audio is rejected automatically through heuristic validation.

API quickstart

Send audio via multipart POST:

curl -X POST http://localhost:5000/upload \
  -F "file=@cry_sample.wav"

Typical JSON response:

{
  "success": true,
  "predicted_class": "hungry",
  "confidence": 0.87,
  "probabilities": {
    "hungry": 0.87,
    "tired": 0.05,
    "cold_hot": 0.03,
    "discomfort": 0.03,
    "belly pain": 0.02
  }
}

Performance notes

  • Latency designed for near real-time feedback (~220 ms).
  • Accuracy 85–92% depending on cry category balance.
  • Confidence threshold & heuristics guard against non-cry audio.
  • Future improvements planned via broader data coverage.
